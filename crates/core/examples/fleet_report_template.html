Scripture Sous-Chef — fleet report

Sous-Chef reads a Bible translation draft and points out mechanical problems — damaged characters, leftover markup, typos the keyboard made, punctuation that breaks the text's own habits. It never judges wording or meaning, and it learns each translation's conventions from that translation alone: nothing from any other language is used to judge a text.

This report is the quality control for the checker itself. Every check was run against every real translation below. A trustworthy check must be quiet on healthy text and loud on damage — these charts show exactly how quiet and how loud each one is in practice.

How big are the translations in this fleet?

Each bar counts translations of a given size. A full Bible is ≈31,000 verses; a New Testament ≈8,000.

How to read the charts

dot = one translation In the dot charts, each dot is one translation, placed by how many findings the check raised per 1,000 verses there (note the scale steps by ×10). Dots near the left barely heard from the check; dots far right are texts where it found a lot — hover any dot for the translation's name. Translations with zero findings don't get a dot; the caption counts them.

seen, judged normal shown to a reviewer Some checks score every candidate between 0 (“this is just how this text writes”) and 1 (“this text almost never does this — look at it”). The histograms show all candidates; only the blue part, right of the confidence bar, is ever shown to a person. The grey mass is the check recognising a text's own conventions and staying quiet about them.

For this survey every check was switched on for every translation, including the ones the product ships switched off — that's the point: to measure what they would say.
