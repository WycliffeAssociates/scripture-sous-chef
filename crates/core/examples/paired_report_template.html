prop.length-ratio compares each verse's length against the source it was translated from — a per-book median/MAD robust-z gate, flagged past . This report is the paired harness that rule has never had: real target/source pairs, a versification-quarantine guard for mis-paired books, and (when run with --seed-faults) a deterministic ground truth for how well the rule catches damage it was designed to catch.

Per-pair detail

Generated by cargo run --release -p ssc-core --example calibrate -- --paired-survey <pairs.tsv> <out-dir> (or --seed-faults). Manifest: documentation/calibration/corpora-pairs.tsv. Method: per book, median + MAD (0.6745 scale) of the target/source grapheme-length fraction; a verse fires past |z| > the threshold. A book whose own median fraction is a robust outlier against the pair's other book medians is quarantined (a pairing/versification artifact) and never contributes findings.
