# The Rule Playbook — moved

This catalog has moved to per-family files under
[`documentation/rules/`](rules/README.md), keyed by rule-id namespace
(`hyg.*`, `uni.*`, `lex.*`, `struct.*`, `punct.*`, `prop.*`, `case.*`).

The old content here used stale rule ids (`orth.script-mixing`,
`pos.sentence-start-case`, `src.proportionality`, …) that no longer match the
engine. See [`rules/README.md`](rules/README.md) for the current rule list.
