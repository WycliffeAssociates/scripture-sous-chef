# Plans

Fully-scoped implementation plans — the committed, high-fidelity successor of
an idea (`../ideas/README.md` describes the lifecycle). A plan at the top
level here is **open work**; once a plan lands (its ADR written, its gates
passed) it moves to `completed/` and is kept as the permanent record — plans
are the highest-fidelity artifact of the lifecycle, so completed plans are
never deleted. Each completed plan's header names the ADR(s) that record what
actually shipped; where plan and ADR disagree, the ADR is the authority.
