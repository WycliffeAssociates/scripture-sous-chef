# Doubtful rules — the container

Rule ideas that are probably not worth building, kept with their reasoning
so they are re-litigated deliberately or not at all. From the dissolved
2026-07-07 shortlist, 2026-07-29.

## Sentence-START positional rule — doubtful pending base-rate scrutiny

"This frequent word starts a sentence approximately never — yet here it is."
Works in caseless scripts (by word identity), Zipf-gated ≥10×. Doubtful
because its sentence-END twin died on exactly the shape this one has:
rarity-shaped evidence measures rarity, not wrongness — poetic inversion and
quoted fragments are precisely as rare as errors. Before any build, run the
same rare-but-valid base-rate scrutiny that killed the end side. Position
machinery exists (adjacency to validated terminals via ADR 0052) — never
verse boundaries.

## Chapter-end punctuation — doubtful for need, not cost

"What fraction of chapters end with a terminal mark" — an honest learned
habit (paragraph-final punctuation observed at a convenient boundary),
Wilson-dominance self-gating, cheap on the census walks. Doubtful because no
user or corpus has ever asked for it; it is a rule in search of a need. NOT
already covered by ADR 0052 (that is per-mark boundary trust, not
chapter-final coverage).
