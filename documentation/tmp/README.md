# tmp — scratch & handoffs

A durable-but-disposable drawer: in-flight progress trackers, cross-tool /
cross-agent handoff notes, and working docs that need to survive a session
and travel with the repo but aren't canonical.

Not a graveyard. Once the work a doc tracks has landed, its lasting record
belongs elsewhere — the decision in an `../adrs/` entry, the rule write-up
in `../rules/`, the measurement in `../calibration/`. Files here are fair
game to delete once that's true.

(Distinct from a session's ephemeral agent scratchpad under the OS temp
dir, which never enters the repo at all.)
